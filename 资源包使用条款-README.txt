【 关于本包的技术保护 】
------------------------------------------------------------
本包做了结构保护处理。用常规解压软件打开时，可能会提示「文件
已损坏」；也可能虽然能提取出文件，但内容无法使用 —— 这都属于
正常的保护效果，不是文件出了问题。

直接放进 .minecraft/resourcepacks 文件夹即可正常使用。不需要
解压，也不用尝试修复。
